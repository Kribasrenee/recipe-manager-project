REST API

Core Endpoints

GET /v1/recipes List & search recipes with filters
GET /v1/recipes/:id Full recipe with steps & nutrition
GET /v1/ingredients/:id Ingredient details and substitutes
POST /v1/collections Create a saved recipe collection
GET /v1/cuisines Browse all available cuisine types
DEL /v1/collections/:id Remove a saved collection
